# tomzefk.dev

It's my small corner of the internet where I share what I'm building, what I'm learning, and the things I'm curious about.

The website itself is also an ongoing experiment. I'll use it to explore ideas around interaction, real-time experiences, and connecting the web with things happening outside of it.

## Built with

* [Astro](https://astro.build/)
* [SCSS](https://sass-lang.com/)

The site is built with Astro to keep the majority of the website lightweight and static, while leaving room for interactive components where they make sense.

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
